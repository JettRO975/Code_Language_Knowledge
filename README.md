# Code_Language_Knowledge

个人代码知识库，整理 Java 与 MySQL 的复习笔记。大笔记已按章节拆成单篇，用 Obsidian 双链互相关联。

## 入口

| 主题 | 索引页 | 章节 |
| --- | --- | --- |
| Java 基础 | [[Java基础]] | 泛型、红黑树、lambda表达式、集合、异常、File、IO流、Stream流、方法引用、多线程基础、网络编程 |
| Java 并发 | [[多线程]] | 线程状态、线程池、volatile关键字、原子性、并发工具类 |
| MySQL | [[MySQL基础]] | SQL、函数、约束 |
| 工具库 | [[commons-io]] | IOUtils、FileUtils、FilenameUtils |

## 组织方式

- 每个主题一个文件夹，文件夹内以同名的索引页作为入口。
- 单篇笔记末尾的「相关笔记」一节用 `[[双链]]` 关联，可在 Obsidian 的关系图谱里查看。
- 图片存放在各主题文件夹的 `assets/` 下，使用相对路径引用。

## 说明

笔记由 StackEdit 导出后整理：统一标题层级、清除导出残留、修正少量拼写，并按章节拆分为独立笔记。
